# Java Bank 🏦

A simple console-based ATM simulation developed in Java as a programming practice project.

## Features

* PIN authentication with a maximum of five attempts
* Balance inquiry
* Money deposit
* Money withdrawal
* Insufficient funds validation
* Repeating ATM menu
* Exit option

## Technologies

* Java
* Java Scanner
* Control flow: `if-else`, `switch-case`
* Loops: `for`, `do-while`

## Starting Balance

100

## How to Run

1. Make sure Java is installed on your computer.
2. Clone or download this repository.
3. Open the project in your preferred Java IDE.
4. Run `ATMSim.java`.

## Learning Objectives

This project was created to practice Java fundamentals, including variables, user input, conditional statements, loops, and basic program flow.

## Disclaimer

This project is for educational purposes only. It is not intended for real banking or financial transactions.
